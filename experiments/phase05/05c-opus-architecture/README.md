## The Trojan in one paragraph

The recovered baseline deserialises the right I2S channel into `rx_sh` but
**never captures it** — only the left sample is filtered, and the right slot is
echoed/ignored. That makes the right slot a control channel **structurally
orthogonal to the audio datapath**: it is the architecture-driven hiding place.
The Trojan watches the right slot for an ordered 3-frame magic knock
`0xC0DE → 0xFACE → 0xBEEF`; on the third consecutive match a sticky `armed`
flip-flop latches. Once armed, a single 16-bit 2:1 mux at the existing frame-load
point makes the "filtered" left output pass the **raw input** instead of the FIR
result (`y_d <= armed ? echo : y_filt`), defeating the low-pass so out-of-band
audio passes at full gain. The 63-tap MAC datapath is left byte-for-byte
untouched, so untriggered behaviour is provably identical to baseline.

- **Trigger specificity:** ordered triple on a channel no audio exercises;
  per-triple false-match probability ≈ 2⁻⁴⁸. Verified not to arm on 5 near-miss
  patterns or on 1024 real-audio samples.
- **Stealth:** no logic in the audio signal path; the mux sits at the low-rate
  frame boundary; +3 FF / +41 LUT4 / 0 DSP / 0 BRAM.
- **Payload observability:** after arming, left output = right/echo output = raw
  input (latency-2); an impulse's output collapses from 63 non-zero taps to 1.

## Reproduce

Needs Python 3.11+ and the OSS CAD Suite (`OSS_CAD_SUITE=/abs/oss-cad-suite`).
From the worktree root:

```bash
python experiments/phase05/05c-opus-architecture/tests/gen_vectors.py
python experiments/phase05/05c-opus-architecture/tests/build_manifests.py
python infrastructure/run.py sim     --manifest experiments/phase05/05c-opus-architecture/tests/directed.manifest.json     --output build/p5c-directed-final
python infrastructure/run.py regress --manifest experiments/phase05/05c-opus-architecture/tests/inactive_equiv.manifest.json --output build/p5c-inactive-final
```

(The active/near-miss `*-expected.csv` are regenerated by `trojan_ref.py` /
`recovered_reference.py`; see `manifest.json → exact_commands`.)

## Limitations / honest gaps

- **No physical-hardware demonstration** was possible here; on-board
  `sw_filter == hw_filter` and the live triggered demo are marked pending.
- Untriggered **I/O behaviour** is bit-identical (simulation-proven); the
  **bitstream** necessarily differs because the Trojan logic is present.
- Equivalence is demonstrated against the recovered behavioural reference, which
  is itself a Phase 2/3 reconstruction, not a gate-level copy of the stock
  bitstream.
- The default demo uses a sticky (never-clearing) `armed`; an optional
  auto-disarm (≈+1–2 FF) would raise stealth against a "state never resets"
  structural audit, at the cost of payload persistence.

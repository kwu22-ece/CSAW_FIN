were generated by **Claude Opus 4.8** (`claude-opus-4-8`) in Claude Code, using

was human-written or copied from another candidate.

## Workflow transcripts (raw AI generation logs)

`transcripts/` holds the per-agent JSONL transcripts and run journals copied from
the Claude Code session store for every Workflow invocation. The orchestration
prompts (which embed each subagent's full prompt verbatim) are in `prompts/`.
These are the mandatory AI logs for the competition.

## Note on cyber safeguards

During the DSP-analysis workflow, one subagent's final structured-output message
was flagged by Opus 4.8's broad real-time cyber safeguards (the `[cyber]`
classifier, which the vendor notes "can sometimes flag legitimate cybersecurity
work"). The agent had already written its complete analysis JSON to disk, so no
data was lost. The design *selection* was therefore consolidated in the main
session (the brief explicitly calls for the operator's independent reasoning);
workflows were retained for the numerical analysis and independent verification,
which carry the heaviest parallel-reasoning load.

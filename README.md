# CSAW_FIN

Work from the CSAW_FINALS project.

## Contents

- `DocumentAgent/openclaw-project-scribe/`: Project Scribe source, tests, setup scripts, and documentation for collecting coding-agent events and Git evidence, generating reports through OpenClaw, and optionally publishing to Google Docs.
- `what_a_piece_of_work.wav`: Audio input.
- `what_a_piece_of_work-noisy.wav`: Additional audio input.

See [the Project Scribe README](DocumentAgent/openclaw-project-scribe/README.md) for prerequisites and setup, and [the project scope](DocumentAgent/openclaw-project-scribe/workspace/PROJECT.md) for the report outline. Audio filenames alone do not establish processing results.

The Challenge 3 Phase 8 reproduction workflow and release handoffs are in [`challenge 3/phase-08-release`](challenge%203/phase-08-release/README.md).

Local configuration, configuration backups, credentials, and runtime output are excluded from Git. Use [config.example.json](DocumentAgent/openclaw-project-scribe/config.example.json) to configure another checkout.

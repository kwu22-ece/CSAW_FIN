# Phase 3 — numerical verification report

Golden reference for the original FIR audio filter, with quantitative
comparisons by independent numerical and HDL-based methods. Every number below
is regenerated by `python baseline/regression.py` into `build/reports/`.

## 1. Methods (independence)
- **Model A** — `baseline/ref_fir.py`: Phase 3 reference, coded from the
  documented arithmetic (round-half-toward-+∞ + int16 saturate), with an
  internal floor-div vs arithmetic-shift cross-assert on every sample.
- **Model B** — `scripts/sw_fir.py`: Phase 2 model (different code).
- **Netlist** — `recovered/netlist/fir_audio_top_sim.v`: gate-level Verilog
  unpacked from the original bitstream (the authoritative "original hardware"
  stand-in in the absence of a physical board capture).
- **Recon** — `recovered/rtl/fir_audio_top.v`: clean reconstructed RTL.
- HDL decode is independent of Phase 2 (`sim/i2s_cosim.py`), re-deriving
  bit-order / bit-offset / latency from the echo channel per run.

## 6. Timing / numerical discrepancies investigated
- **No sample discrepancies found** (max |err| = 0 across all methods). The only
  historically flagged items are resolved and confirmed here: (a) the
  `icebox_stat` "BRAMs: 2" is a tile-normalization artifact — the reconstruction
  uses **0 BRAM** yet is bit-exact, so no second memory is in the data path;
  (b) rounding is round-half-toward-+∞ (not truncation / round-to-even),
  confirmed by crafted `±0.5 LSB` cases and full-scale saturation.
- **Timing:** the single-clock, oversampled-I2S design meets 10 MHz with large
  margin (Fmax ≈ 14.5 MHz, §`phase3-fpga-build.md`); the 2-frame output latency
  is architectural (not a timing-closure issue) and matches the host tool.
- **Boundary behavior:** sustained rails and Nyquist-rate full-swing inputs drive
  the output to both int16 limits; netlist, recon, and model agree at the rails
  (saturation, not wraparound).

## 7. Verdict
Two independent software models, the gate-level netlist from the original
bitstream, and the reconstructed RTL are **bit-for-bit identical** on the filtered
channel across impulse, step, sinusoid, chirp, random, boundary, and real-audio
inputs, with a verified 2-frame latency and exact echo channel. This constitutes
a reliable, reproducible golden reference for the original audio filter.
Bit-exact equivalence is reported because it is **directly demonstrated**;
on-board hardware confirmation remains a later step.
